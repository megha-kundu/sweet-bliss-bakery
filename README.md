## 📌 About The Project

Sweet Bliss Bakery is a full-stack online bakery application designed to provide a smooth shopping experience. Customers can explore bakery products, browse categories, create an account, add products to their basket, and place delivery orders.

The application uses **React** for the frontend, **Node.js and Express** for the backend, and **MongoDB** for storing products, users, and orders.

---

## ✨ Key Features

* 🧁 Responsive bakery storefront
* 🍰 Product catalog with real bakery images
* 🔎 Category-based product browsing
* 👤 Customer signup and login
* 🔐 JWT-based authentication
* 🔒 Password hashing with bcryptjs
* 🛒 Persistent shopping basket
* ➕ Quantity management
* 📦 Delivery checkout form
* 🧾 Order creation and storage
* 💾 MongoDB database integration
* 📱 Responsive design for desktop and mobile
